# Srushti Choudhari — Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open the `Srushti-Portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

No installation or build command is required.

## Personalize before publishing
- Replace `assets/profile-placeholder.svg` with your own photo (keep the filename, or update the image path in `index.html`).
- Add certificate cards and links in the Certifications section whenever you are ready.
- Add your resume PDF and link it from the Resume section when ready.
- Replace each project GitHub profile link with the direct repository URL.
- Add your own contribution details to the group projects (CineMatch, MoolyaSetu and FarmBuddy).
- Review the skills list and remove any technologies you have not used.
- Update project descriptions as needed to accurately reflect your work.
